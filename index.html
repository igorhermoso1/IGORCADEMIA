🏗 Estructura HTML
Todo documento HTML tiene una estructura base obligatoria. ¡Sin ella, el navegador no sabe qué hacer!

La estructura mínima de cualquier documento HTML:

<!DOCTYPE html>
<html lang="es">
  <head>
    <meta charset="UTF-8">
    <title>Mi página</title>
  </head>
  <body>
    <!-- contenido visible -->
  </body>
</html>

El <head> contiene metadatos invisibles. El <body> contiene todo lo que el usuario ve.

💡 Siempre incluye lang="es" en el html para indicar el idioma. Los lectores de pantalla y el SEO lo agradecen. Además, charset="UTF-8" evita problemas con caracteres especiales como ñ o á.

¿Sabías que el DOCTYPE no es una etiqueta HTML? Es una instrucción para el navegador que le dice qué versión de HTML estás usando. <!DOCTYPE html> activa el modo estándar HTML5.

🏷 Etiquetas Semánticas
Las etiquetas semánticas dan significado al contenido. Son clave para accesibilidad y SEO.

HTML5 introdujo etiquetas semánticas:

  • <header> — Cabecera
  • <nav> — Navegación
  • <main> — Contenido principal
  • <article> — Contenido independiente
  • <section> — Sección temática
  • <aside> — Contenido lateral
  • <footer> — Pie de página

Antes de HTML5, todo era <div>. Los motores de búsqueda no entendían la estructura. Ahora Google puede identificar el artículo principal, la navegación y el footer de tu página gracias a las etiquetas semánticas.

🎯 Selectores CSS
Los selectores son el corazón de CSS. Sin ellos no puedes aplicar ningún estilo.
/* Elemento */ p { color: red; }
/* Clase */ .card { padding: 10px; }
/* ID */ #hero { font-size: 2rem; }
/* Descendiente */ div p { color: blue; }
/* Hijo directo */ ul > li { list-style: none; }
/* Selector universal */ * { box-sizing: border-box; }
/* Adyacente */ h1 + p { font-weight: bold; }
/* Atributo */ input[type="email"] { border-color: blue; }

El selector * (universal) selecciona TODOS los elementos. Igor lo usa siempre al inicio: * { box-sizing: border-box; margin: 0; padding: 0; } — es el "reset" más básico del mundo CSS.

📦 Box Model
Todo elemento HTML es una caja. El Box Model define cómo se calcula su tamaño y espacio.

Las 4 capas del Box Model (de afuera hacia adentro):

  • margin — Espacio EXTERNO (fuera del borde)
  • border — El borde del elemento
  • padding — Espacio INTERNO (entre borde y contenido)
  • content — El contenido real

box-sizing: border-box — Hace que padding y border se incluyan dentro del width. ¡Úsalo siempre!

🌈 Colores CSS
CSS ofrece múltiples formas de definir colores. Cada una tiene su uso ideal.
/* Nombre */ color: red;
/* HEX */ color: #ff0000; /* o #f00 (shorthand) */
/* RGB */ color: rgb(255, 0, 0);
/* RGBA */ color: rgba(255, 0, 0, 0.5);
/* HSL */ color: hsl(0, 100%, 50%);
/* Variable */ color: var(--mi-color);
/* Gradiente */ background: linear-gradient(135deg, #7c3aed, #06b6d4);

HSL (Hue, Saturation, Lightness) es el formato más intuitivo. El primer valor es el color en grados (0=rojo, 120=verde, 240=azul), el segundo es saturación y el tercero luminosidad. Igor lo usa mucho para crear paletas coherentes.

🖥 Display & Position
Controla cómo se muestran y posicionan los elementos. ¡Fundamental para cualquier layout!

display: block | inline | inline-block | none | flex | grid

position:

  • static — Default, flujo normal
  • relative — Relativo a su posición normal
  • absolute — Relativo al padre posicionado más cercano
  • fixed — Fijo al viewport (como barras de nav)
  • sticky — Como relative hasta que hace scroll, luego fixed

position: sticky es la combinación perfecta de relative y fixed. El menú de navegación que se queda fijo al hacer scroll, pero que empieza en su posición normal — eso es sticky. ¡Igor lo usa siempre para navbars!

🧲 Flexbox
Flexbox es el sistema de layout más usado. ¡Con 3 propiedades centras cualquier cosa!
.container {
  display: flex;
  flex-direction: row | column;
  justify-content: flex-start | center | flex-end | space-between | space-around | space-evenly;
  align-items: flex-start | center | flex-end | stretch | baseline;

Propiedades de hijos: flex-grow, flex-shrink, order, align-self

La regla de oro de Igor: display:flex; justify-content:center; align-items:center; centra cualquier cosa horizontal y verticalmente. ¡Memorízala!

🔲 CSS Grid
CSS Grid es el sistema de layout más potente para dos dimensiones. ¡Domínalo paso a paso!
.container {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr; /* 3 cols iguales */
  grid-template-columns: repeat(3, 1fr); /* equivalente */
  grid-template-rows: auto 1fr auto;
  gap: 16px;
}
/* Responsive mágico */
grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));
/* Span — ocupar varias columnas */
.hero { grid-column: 1 / -1; }

auto-fit vs auto-fill: con auto-fit, si hay espacio sobrante los items crecen para llenarlo. Con auto-fill, se crean columnas vacías. Igor casi siempre usa auto-fit.
