🏗 Estructura HTML
Todo documento HTML tiene una estructura base obligatoria. ¡Sin ella, el navegador no sabe qué hacer!

La estructura mínima de cualquier documento HTML:

<!DOCTYPE html>
<html lang="es">
  <head>
    <meta charset="UTF-8">
    <title>Mi página</title>
  </head>
  <body>
    <!-- contenido visible -->
  </body>
</html>

El <head> contiene metadatos invisibles. El <body> contiene todo lo que el usuario ve.

💡 Siempre incluye lang="es" en el html para indicar el idioma. Los lectores de pantalla y el SEO lo agradecen. Además, charset="UTF-8" evita problemas con caracteres especiales como ñ o á.

¿Sabías que el DOCTYPE no es una etiqueta HTML? Es una instrucción para el navegador que le dice qué versión de HTML estás usando. <!DOCTYPE html> activa el modo estándar HTML5.

🎯 Selectores CSS
Los selectores son el corazón de CSS. Sin ellos no puedes aplicar ningún estilo.
/* Elemento */ p { color: red; }
/* Clase */ .card { padding: 10px; }
/* ID */ #hero { font-size: 2rem; }
/* Descendiente */ div p { color: blue; }
/* Hijo directo */ ul > li { list-style: none; }
/* Selector universal */ * { box-sizing: border-box; }
/* Adyacente */ h1 + p { font-weight: bold; }
/* Atributo */ input[type="email"] { border-color: blue; }

El selector * (universal) selecciona TODOS los elementos. Igor lo usa siempre al inicio: * { box-sizing: border-box; margin: 0; padding: 0; } — es el "reset" más básico del mundo CSS.

📦 Box Model
Todo elemento HTML es una caja. El Box Model define cómo se calcula su tamaño y espacio.

Las 4 capas del Box Model (de afuera hacia adentro):

  • margin — Espacio EXTERNO (fuera del borde)
  • border — El borde del elemento
  • padding — Espacio INTERNO (entre borde y contenido)
  • content — El contenido real

box-sizing: border-box — Hace que padding y border se incluyan dentro del width. ¡Úsalo siempre!

🌈 Colores CSS
CSS ofrece múltiples formas de definir colores. Cada una tiene su uso ideal.
/* Nombre */ color: red;
/* HEX */ color: #ff0000; /* o #f00 (shorthand) */
/* RGB */ color: rgb(255, 0, 0);
/* RGBA */ color: rgba(255, 0, 0, 0.5);
/* HSL */ color: hsl(0, 100%, 50%);
/* Variable */ color: var(--mi-color);
/* Gradiente */ background: linear-gradient(135deg, #7c3aed, #06b6d4);

HSL (Hue, Saturation, Lightness) es el formato más intuitivo. El primer valor es el color en grados (0=rojo, 120=verde, 240=azul), el segundo es saturación y el tercero luminosidad. Igor lo usa mucho para crear paletas coherentes.

🖥 Display & Position
Controla cómo se muestran y posicionan los elementos. ¡Fundamental para cualquier layout!

display: block | inline | inline-block | none | flex | grid

position:

  • static — Default, flujo normal
  • relative — Relativo a su posición normal
  • absolute — Relativo al padre posicionado más cercano
  • fixed — Fijo al viewport (como barras de nav)
  • sticky — Como relative hasta que hace scroll, luego fixed

position: sticky es la combinación perfecta de relative y fixed. El menú de navegación que se queda fijo al hacer scroll, pero que empieza en su posición normal — eso es sticky. ¡Igor lo usa siempre para navbars!

🎲 Transformaciones 3D CSS
Dale profundidad a tu interfaz con perspectiva, rotaciones 3D y el clásico efecto de tarjeta flip.

CSS puede transformar elementos en el eje Z (profundidad):

/* Perspectiva en el padre */

/* Transformaciones 3D */
transform: rotateX(45deg); /* gira eje X */
transform: rotateY(180deg); /* gira eje Y */
transform: translateZ(100px); /* aleja/acerca */

/* Para tarjetas flip */
transform-style: preserve-3d; /* hijos en 3D */
backface-visibility: hidden; /* oculta cara trasera */

/* En hover del contenedor */
transform: rotateY(180deg);

Estructura de una tarjeta flip:

  • Contenedor: perspective + transform-style: preserve-3d
  • Cara frontal: normal
  • Cara trasera: rotateY(180deg) + backface-visibility: hidden
  • En hover: rotateY(180deg) en el contenedor interno

El valor de perspective define la "distancia del ojo". Valores pequeños (300px) dan un 3D muy exagerado. Entre 800-1200px es lo que Igor usa para efectos de UI elegantes. Puedes combinarlo con perspective-origin para cambiar el punto de fuga.

Los navegadores usan la GPU para renderizar transform y opacity. Son las dos propiedades que no provocan reflow ni repaint y se ejecutan en el compositor gráfico. Por eso las animaciones con transform son siempre a 60fps, mientras que animar width o top puede ser costoso.

📐 Unidades CSS
Saber cuándo usar px, rem, %, vw o clamp() es la diferencia entre código frágil y código robusto.

📚 Z-index & Stacking Context
Uno de los conceptos más confusos de CSS. Aprende de una vez cómo funciona el apilamiento visual.

z-index controla qué elemento aparece por encima de otros:

Orden de apilamiento sin z-index (de abajo a arriba):

☑️ Checkbox Trick
El truco más poderoso de CSS puro: modales, acordeones, tabs y menús interactivos sin una sola línea de JavaScript.

La idea: un <input type="checkbox"> oculto + un <label> como botón + el selector ~ para controlar elementos hermanos.

<!-- HTML: el checkbox actúa como interruptor -->
<input type="checkbox" id="toggle" class="hidden-check">
<label for="toggle" class="btn">Abrir panel</label>
<div class="panel">Contenido oculto</div>

/* CSS: ocultar el checkbox real */
.hidden-check { display: none; }

/* El panel está oculto por defecto */
.panel { max-height: 0; overflow: hidden; transition: .4s; }

/* Cuando el checkbox está marcado, muestra el panel */
.hidden-check:checked ~ .panel {
  max-height: 500px;
}

/* Cambiar el label cuando está activo */
.hidden-check:checked ~ .btn {
  background: #7c3aed;
}

Con esta técnica puedes hacer:

  • Acordeones FAQ — múltiples checkboxes, uno por sección
  • Menú hamburguesa — checkbox + label como icono ☰
  • Tabs — radio buttons (solo uno activo a la vez) + :checked ~ .tab
  • Modal/overlay — checkbox global que muestra un overlay fijo
  • Modo oscuro — checkbox en el body con :checked ~ * {}

El selector ~ (hermano general) es el héroe aquí: selecciona todos los hermanos que vienen después. El selector + (hermano adyacente) solo selecciona el inmediatamente siguiente. Para tabs usa <input type="radio"> en lugar de checkbox: los radio solo permiten una opción activa a la vez dentro del mismo name.

Esta técnica se llama "Checkbox Hack" y fue popularizada por Chris Coyier en CSS-Tricks (2012). Aunque ahora tenemos <details> para acordeones y la API Popover para modales, el checkbox hack sigue siendo útil por su compatibilidad universal y porque no requiere ningún JS en el bundle.

Más allá de lo básico: subgrid, named lines, dense packing y técnicas de layout que marcan la diferencia.
/* Named lines — líneas con nombre */

🌐 Propiedades Lógicas CSS
El CSS moderno que no depende de "izquierda/derecha" sino de "inicio/fin". Esencial para webs multiidioma y RTL.
/* Físico → Lógico */
margin-left → margin-inline-start
margin-right → margin-inline-end
margin-top → margin-block-start
margin-bottom → margin-block-end

/* Shorthand lógico */
margin-inline: auto; /* = margin-left + margin-right: auto */
margin-block: 2rem 1rem; /* = margin-top + margin-bottom */
padding-inline: 1rem;
padding-block: 2rem;

/* inset = top + right + bottom + left */
inset: 0; /* equivale a top:0; right:0; bottom:0; left:0 */
inset-inline: 0; /* left:0 + right:0 */

/* Sizing lógico */
inline-size: 400px; /* = width en modo horizontal */
block-size: 200px; /* = height en modo horizontal */

El truco más útil del día a día: en lugar de margin-left: auto; margin-right: auto; para centrar un bloque, usa simplemente margin-inline: auto. Es más corto, más semántico y funciona en cualquier dirección de escritura.

Las propiedades lógicas son el futuro del CSS. Frameworks como Tailwind v4 y el diseño de Material Design 3 las usan por defecto. En webs con idiomas RTL (árabe, hebreo) o modos de escritura verticales (japonés, chino tradicional), las propiedades lógicas se adaptan automáticamente sin una sola línea extra de CSS.

🎯 :has() :where() :is()
Los selectores CSS más poderosos de la historia moderna. :has() es el "if" de CSS: selecciona padres según sus hijos.
/* :is() — agrupa selectores, reduce repetición */
/* En lugar de: h1 a, h2 a, h3 a, h4 a */
:is(h1, h2, h3, h4) a { color: #7c3aed; }

/* :where() — igual que :is() pero especificidad 0 */
:where(h1, h2, h3) a { color: blue; }

/* :has() — selecciona el PADRE según sus hijos */
/* Tarjeta que tiene imagen: más altura */
.card:has(img) { min-height: 300px; }

/* Form con input inválido: borde rojo */
form:has(input:invalid) { border: 2px solid red; }

/* Párrafo que sigue a un h2: mayor margen */
h2 + p { margin-top: 0; }

/* :not() combinado con :has() */
.card:not(:has(img)) { background: #f5f5f5; }

La diferencia clave entre :is() y :where() es la especificidad. :is() toma la especificidad del selector más específico dentro. :where() siempre tiene especificidad 0, lo que lo hace perfecto para estilos base que se puedan sobreescribir fácilmente. Ideal para design systems.

:has() es el selector "padre" que la comunidad CSS llevaba pidiendo desde 2005. Tardó casi 20 años en llegar (soporte completo en 2023) porque su implementación eficiente era muy compleja para los motores de renderizado. Ahora cambia paradigmas: puedes condicionar estilos de un padre según cualquier estado de sus hijos.
